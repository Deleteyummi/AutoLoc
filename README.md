# \# AutoLoc

# Plateforme de gestion de location de véhicules multi-agences

# 

# \## Objectifs du projet

# Développer une application de gestion de location de véhicules pour plusieurs agences.

# 

# \## Acteurs identifiés

# \- \*\*Client\*\* : consulte et réserve des véhicules

# \- \*\*Agent d'agence\*\* : gère les réservations et les retours

# \- \*\*Responsable d'agence\*\* : supervise l'activité de son agence

# \- \*\*Administrateur\*\* : gère l'ensemble de la plateforme
